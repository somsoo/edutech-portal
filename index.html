COGNITIVE SCIENCE ARCHITECTURE

인지과학 기반 인터랙티브 학습 설계 원칙

서버리스 웹 표준 기술로 구현된 4대 핵심 인지과학 메커니즘 해설

전통적인 이러닝(e-Learning) 환경은 동영상 강의를 수동적으로 시청하거나 PDF 문제집을 스크롤하는 '수동적 수용(Passive Consumption)' 구조에 머물러 있었습니다. 그러나 인지과학 연구에 따르면, 뇌는 단순히 정보를 볼 때보다 직접 손가락으로 조작하고 오차를 즉각적으로 교정받을 때 시냅스 연결을 수십 배 더 견고하게 형성합니다.

🔄 간격 반복 (Spaced Repetition)

에빙하우스 망각곡선 모델과 FSRS 알고리즘을 브라우저에 직접 탑재하여, 잊어버리기 직전 최적의 복습 타이밍을 기계적으로 계산해 장기기억으로 전환합니다.

🧠 능동 회상 (Active Recall)

단순히 정답을 눈으로 확인하는 재인(Recognition)이 아닌, 스스로 인출 단서를 떠올리는 인출 연습을 3D 플립 카드 및 빈칸 천공(Cloze)으로 강제합니다.

⚡ 즉각적 교정 피드백 (Immediate Feedback)

조작 후 결과 판정까지의 지연 시간이 50ms 미만으로 유지될 때 뇌는 행위와 결과의 인과관계를 체득합니다. Canvas 2D 60fps 연산으로 오차를 즉시 보여줍니다.

🎨 이중 부호화 (Dual-Coding Theory)

언어적 텍스트 정보와 비언어적 시각·청각 모델(분수 피자, 텐프레임 음계 등)을 동시에 동기화하여 작업 기억의 인지 부하를 줄이고 이해 속도를 극대화합니다.

1. 발달 단계별 인지적 특성을 반영한 4대 계층 설계

유아기 (3~7세)는 오류 상태(Failure State)가 없는 직관적 감각 놀이가 필수적입니다. 화면 어디를 만져도 실패하지 않고 기분 좋은 시청각 피드백(실로폰 음계, 자모 결합 텐션 애니메이션)을 제공하여 호기심과 수 감각을 자연스럽게 틔워줍니다.

초등기 (8~13세)는 구체적 조작기에서 형식적 조작기로 넘어가는 결정적 시기입니다. 분수, 구구단, 단위 환산처럼 추상적인 기호 수학에 질려 수포자가 되기 쉬운 개념들을 기하학적 면적 모델과 무한 줌 슬라이서로 시각화하여 수학적 직관을 심어줍니다.

중·고등기 (14~19세)는 복합 개념의 원리 이해와 방대한 어휘·공식 암기가 요구됩니다. 실시간 함수 모핑과 베를레 물리 수치적분 시뮬레이터로 공식을 체감하고, FSRS 간격 반복 보카 엔진으로 수험 어휘를 효율적으로 정복합니다.

성인 수험생 (20세 이상)은 메타인지와 딥워크 몰입 시간 관리가 핵심입니다. 뽀모도로 타이머와 집중도 회고 로그, 무한 로직 트리, LaTeX 실시간 수식 추출을 통해 학술 연구와 수험 생활의 생산성을 극대화합니다.

2. 100% 클라이언트 사이드 연산과 제로 트래킹 프라이버시

본 포털의 모든 학습 도구는 백엔드 서버나 외부 데이터베이스에 의존하지 않습니다. 모든 연산과 데이터 저장은 학습자의 브라우저 로컬 저장소(IndexedDB / LocalStorage)에서만 독립 실행됩니다. 따라서 사용자의 오답 노트, 집중도 기록, 생성한 덱은 어떤 외부 서버로도 전송되지 않으며, 학교나 학원 교실에서도 개인정보 유출 우려 없이 안심하고 사용할 수 있습니다.
